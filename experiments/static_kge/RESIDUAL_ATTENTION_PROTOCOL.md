# 第二阶段残差注意力实验协议

首轮四个预注册模型的开发集结果表明，等权平均（MRR 0.593）优于无残差的关系注意力（0.539），剂量平均（0.579）也未超过等权平均。第二阶段只依据开发集现象设计，测试集数值不用于结构选择。

新增两个候选：`residual_attention`和`dose_residual_attention`。二者将权重定义为“固定平均权重”和“关系条件注意力权重”的凸组合，门控按关系学习并初始化为`sigmoid(-2)=0.119`，使模型从稳定平均附近开始，只在训练证据支持时偏离。剂量版对完整剂量方剂使用剂量比例作为固定基底，其余使用等权基底。

训练超参数、严格归纳划分和开发集选择规则与第一阶段完全相同。两个候选的checkpoint全部冻结后统一测试。若未稳定超过`uniform_mean`，论文方法回退为参数更少、证据更强的组成平均模型，不以注意力作为性能创新。
