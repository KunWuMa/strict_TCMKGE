# 组成感知归纳式KGE预注册实验协议

## 研究问题

给定一个从未在训练图中作为实体出现的中成药，仅使用其饮片组成，能否补全该中成药对应的中医疾病、证候、治法、治则、病因和病机关系？主任务仍是TCM-MKG中的`CPM -> typed TCMT`链接预测。

## 严格归纳划分

沿用冻结的`formula_holdout`开发/测试方剂集合和目标边。训练时移除开发、测试方剂的全部图边；`D4_CPM_CHP.tsv`只作为方剂组成输入，不作为训练三元组。这样，开发/测试方剂没有可学习的ID向量或邻接边，模型只能由组成饮片计算其表示。训练方剂的ICD边和饮片属性、物种、化合物边可作为辅助关系。

## 预先固定的模型

四个模型共享ComplEx评分函数、饮片/术语实体嵌入和关系嵌入；方剂头实体的实部和虚部都由组成饮片聚合得到，不使用方剂ID嵌入。

| 模型 | 聚合规则 |
|---|---|
| uniform_mean | 饮片嵌入等权平均；参数最少的组成基线 |
| dose_mean | 有完整剂量比例时加权平均，无剂量时退化为等权平均 |
| relation_attention | 用待预测关系查询饮片并作softmax加权 |
| dose_relation_attention | 关系查询分数与剂量对数先验联合决定饮片权重 |

剂量字段事先审计：74,084条组成边均可解析；8,766个方剂中3,636个有完整且归一化的比例，5,130个全部缺失，没有部分缺失。缺失时不插补伪剂量。

## 训练与选择

单种子筛选固定为`20260915`，维度128，batch 2048，每个正例8个关系类型约束的负尾实体，Adam学习率0.003，最多40轮，每5轮按严格归纳开发集的类型限定filtered MRR选择checkpoint。所有模型选择完成后统一打开测试集。

若最佳组成模型同时高于频率基线（测试MRR 0.284）和无方剂上下文ComplEx下界（0.081），则运行三个种子并补充随机划分、关系分层、剂量可用性分层与去辅助关系消融。最终是否有论文价值以多种子均值、方差及强KGE对照为准。
