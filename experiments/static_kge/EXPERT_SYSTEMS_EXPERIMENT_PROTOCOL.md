# Expert Systems 投稿实验协议

## 研究问题

- **RQ1：** 在严格归纳场景下，只给定未见方剂的组成药物，药对二阶交互是否能提高方剂—中医术语链接预测？
- **RQ2：** 改进是否来自真实的药对输入，而不是参数量增加、第二条网络分支或模型随机性？
- **RQ3：** 改进是否在不同方剂规模、不同随机种子和不同 KGE 解码器下保持？
- **RQ4：** 模型是否真正依赖正确组成，并在组成缺失时平稳退化？
- **RQ5：** 线性时间药对矩的额外参数量和推理延迟是否可接受，能否产生忠实的模型内药对归因？

## 数据与防泄漏

- 数据源：TCM-MKG 的 `D3_CPM_TCMT.tsv`（目标边）及 `D4_CPM_CHP.tsv`（方剂组成），其余关系只作为训练图上下文。
- 确证划分：`benchmark/hybrid_holdout`，测试集 1,093 条目标边、610 个未见方剂头实体。
- 开发集和测试集中的方剂实体及其所有训练图边均从训练图移除；模型只能从外部组成数组生成其表示。
- 方剂 ID 嵌入仍保留在统一实体表中以便索引，但严格测试验证该嵌入不影响生成结果；改变未见方剂 ID 参数不改变输出。
- 所有超参数和早停轮次只看开发集；同一批比较模型全部选定后才评估测试集。

## 核心模型

对复数药物嵌入集合 $\{z_i\}_{i=1}^{n}$，定义一阶均值和有序药对二阶矩：

$$
\mu=\frac{1}{n}\sum_i z_i,\qquad
p=\frac{1}{n(n-1)}\sum_{i\ne j}z_i\odot z_j.
$$

利用恒等式

$$
\sum_{i\ne j}z_i\odot z_j=\left(\sum_i z_i\right)^{\odot 2}-\sum_i z_i^{\odot 2}
$$

在 $O(nd)$ 时间内计算全部药对交互。方剂表示为

$$
z_f=\mu+\alpha g_u(\mu)+\beta(n)g_p(p),
$$

其中 $g_u,g_p$ 为复值线性变换加双曲正切，$\alpha$ 为可学习门，$\beta(n)$ 为随方剂规模变化的逻辑门。主解码器采用 ComplEx。

## 比较与统计

1. 频率基线、严格 ID-KGE 和均值组成 KGE。
2. DeepSets 一阶非线性组成器。
3. 只含药对残差的模型。
4. **精确参数等量对照：** 与完整模型拥有相同网络和参数量，但用一阶均值替换药对矩输入。
5. ComplEx、DistMult、TransE 解码器迁移。
6. 三个预先固定的随机种子；报告均值、样本标准差。
7. 查询级配对 bootstrap 与按方剂头实体聚类 bootstrap，均为 20,000 次。
8. 按 1–5、6–10、>10 味药分层。

## 稳健性、效率与解释

- 10%、20%、30%、50% 随机缺药，每档五个固定掩码，每个掩码评估三个模型种子。
- 50 次同规模错误组成置换；保持方剂规模、测试查询和模型不变，只交换组成药物。
- 嵌入维度 64、128、256，每档三个随机种子。
- 参数量、FP32 参数存储、检查点大小及 GPU 编码延迟。
- 五个三种子均为 Hits@1 的案例，采用目标分数对药对矩的梯度乘以每个无序药对对二阶矩的贡献，另报告完整分支相对关闭分支的有限干预分数变化。

## 结论边界

药对归因衡量训练模型在给定链接预测中的内部贡献，不等同于中医配伍功效或临床因果效应。当前 TCM-MKG 确证划分属于同语料重划分；独立处方数据集上的外部验证单独报告，不与内部测试混称。


## 扩展 KGE 对照协议

- **RQ6：** PairComp-KGE 相对传统 KGE 解码器及较新的归纳 KGE 方法是否仍有优势？
- 纯 ID 的 TransE、DistMult、ComplEx 作为传导式诊断下界；测试处方 ID 从未获得梯度，因此不把它们当作公平的归纳竞争者。
- 公平的同输入对照均从相同 D4 药物集合生成处方：Mean-ComplEx、Mean-RotatE、Mean-PairRE 和 NodePiece-style Transformer。
- “NodePiece-style”明确表示领域适配：中药实体作为锚点 token；未复现原论文的通用锚点距离词表，不标记为官方 NodePiece 复现。
- InGram 使用官方代码提交 `f2554dd0c684bad71d3e01d534f2f7814cf28644`。训练处方和未见处方的组成边仅进入 message graph，开发/测试目标边不进入消息图。三个种子完整训练 200 轮，按开发集 MRR 选检查点。
- 所有方法在同一 1,093 条查询、610 个处方、关系类型约束 filtered 排名上评估。主要比较采用按处方聚类的 20,000 次 bootstrap。
